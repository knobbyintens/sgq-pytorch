# SGQ-PyTorch

Unofficial implementation of the paper *Shifted-Grid Quantization:
Error-Compensated 4-bit Weight Quantization* (arXiv:2603.04417).

- Language: Python
- License: MIT
- Status: active
- Implements: Shifted-Grid Quantization (SGQ)
- Benchmark (WQ-4 4-bit accuracy retention): 88.6

## Notes

CUDA and CPU paths are provided. Evaluation scripts for WikiText-103
and the WQ-4 calibration set are under `bench/`.
